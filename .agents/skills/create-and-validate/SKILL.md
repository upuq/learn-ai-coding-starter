# Create and Validate

This skill composes two existing skills. Do not duplicate their instructions here; load and follow them in order.

1. Load the `create-test-program` skill and follow its workflow to write the example and add its exact-output test.
2. Load the `validate` skill and follow it to run the project checks.

Summarize which checks passed and which failed. Report failures before proposing fixes.
